# backend（本期为空，这是刻意的）

LiteOffice 的定位是**本地优先**：文件在用户的设备上打开、编辑、保存，全程不经过任何服务器。

因此本期**不实现后端**，具体不做：

- 账号系统、登录、云端文档库
- Document Server、数据库
- 多人实时协作与文件同步

这不是"没做完"，是范围决策。判断依据见：

- `docs/requirements/problem_definition.md` 中"本地优先 / 文件不出设备"的诉求
- `liteoffice-规划-v2.md` 第 1.3 节"明确不做"

保留这个目录是为了沿用课程提供的仓库模板。若后续版本要做团队协作，服务端代码放这里。
