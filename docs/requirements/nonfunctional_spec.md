# 非功能需求规范

LiteOffice｜版本 v1.1｜2026-10-17

| 版本 | 日期 | 说明 |
|---|---|---|
| v1.0 | 2026-10-17 | 初稿，11 类非功能需求 |
| **v1.1** | 2026-10-17 | 合并为 6 类、共 25 条；补充 iframe 架构与本地优先约束 |

每条给出可测量的指标、测量方法与当前实测值。无测量方法的需求不列入。

## 1. 性能（PERF）

| 编号 | 需求 | 指标 | 测量方法 | 实测 | 状态 |
|---|---|---|---|---|---|
| NFR-PERF-01 | 预览首屏时间 | ≤ 1 s | drop 事件到首次内容绘制 | docx < 1 s | ✅ |
| NFR-PERF-02 | 编辑模式首次加载 | ≤ 180 s（首访）；≤ 10 s（已缓存） | 加载遮罩显示的等待秒数 | 本机 5–10 s；局域网 1–3 min | ✅ |
| NFR-PERF-03 | 预览按格式按需加载 | 不交叉下载 | Network 面板过滤 JS | 符合 | ✅ |
| NFR-PERF-04 | 界面响应 | ≤ 100 ms（不含内核加载） | 点击后状态变化是否即时 | 符合 | ✅ |

编辑模式体积构成：`sdkjs/word/sdk-all.js` 6.7 MB、`x2t.wasm` 56 MB、web-apps 与字体约 136 MB。

## 3. 隐私与安全（PRIV / SEC）

| 编号 | 需求 | 指标 | 测量方法 | 实测 | 状态 |

| NFR-PRIV-01 | 文件零上传 | 绝对 | 断网后仍可打开与预览；Network 无上传请求 | 符合（架构上无上传通道） | ✅ |

| NFR-SEC-01 | 不可信输入处理 | 格式判定不只看文件名 | 扩展名 + ZIP 头双重校验 | 已实现 | ✅ |

## 4. 兼容与可用性（COMPAT / USAB）

| 编号 | 需求 | 指标 | 测量方法 | 实测 | 状态 |
|---|---|---|---|---|---|
| NFR-COMPAT-01 | 浏览器支持 | Chrome / Edge 近两年版本可用 | 实际打开验证 | 需 WebAssembly 与新 ES 模块；旧内核浏览器不可用 | ⚠️ |

| NFR-USAB-02 | 长耗时可见 | 超过 1 s 有反馈 | 观察加载遮罩与秒数 | 遮罩 + 等待计时 + 超时提示 | ✅ |

## 6. 合规与测试（LEGAL / TEST）

| 编号 | 需求 | 指标 | 实测 | 状态 |
|---|---|---|---|---|
| NFR-LEGAL-01 | 开源许可可追溯 | 本项目 MIT；第三方许可见 LICENSE | 已标注 ONLYOFFICE 为 AGPL-3.0 | ✅ |
| NFR-LEGAL-02 | 不打包商业字体 | 无商业字体 | **未满足**：包内含 DengXian、SimSun、Arial、Courier New、Wingdings | ❌ |
| NFR-TEST-01 | 静态检查进 CI | 每次 push / PR 执行 | `.github/workflows/ci.yml` | ✅ |
| NFR-TEST-02 | 核心场景文档化 | 验收步骤可重复执行 | `functional_spec.md` 第 5 节 | ✅ |
| NFR-TEST-03 | 自动化测试 | 有单元或 E2E 测试 | **无**，依赖人工验收 | ❌ |

### NFR-LEGAL-02 说明

解析 `public/onlyoffice/fonts/` 中 16 个文件的 TTF `name` 表，确认为
`DengXian`（等线 / 等线 Light）、`SimSun`（宋体）、`Arial`、`Courier New`、
`MS UI Gothic`、`Segoe UI Symbol`、`Symbol`、`Wingdings` —— 均为 Microsoft 商业字体。

课程内网使用风险较低；公开分发、商用或对外提供服务前必须替换为开源字体
（思源黑体 / Noto Sans SC / Liberation / Carlito / Caladea），并回归中文排版与光标位置。
