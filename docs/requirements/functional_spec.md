## 1. 范围与约定

覆盖浏览器端的外部可见功能：打开、预览、编辑、保存、Markdown 预览、AI 辅助写作、界面反馈、错误处理、配置开关。

不覆盖部署运维、桌面打包、多人协作（延后到 v2）、账号与云存储。

| 字段 | 含义 |
|---|---|
| 编号 | `FR-<模块>-<序号>`，全仓库唯一，Issue 可直接引用 |
| 优先级 | P0 必须 / P1 应该 / P2 可选 |
| 验收标准 | 必须可判断真假 |

## 2. 非目标

宏 / VBA、多人协作与版本历史（v2 再评估）、账号与云存储、复杂排版高保真、从零开发 Office 引擎、
PDF 注释与表单。

> 关于 AI：**不做整篇生成**（质量不可控，且与"辅助"定位冲突），只做选区级改写与问答。

## 3. 功能需求

### 3.1 FR-FILE 打开

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-FILE-01 | 点击按钮选择文件，可一次选多个 | P0 | 选 3 个文件后侧栏出现 3 条记录；可单独关闭 |
| FR-FILE-02 | 拖放到窗口任意位置打开 | P0 | 拖入显示虚线遮罩，松开后打开 |
| FR-FILE-03 | 按扩展名 + ZIP 头双重识别，非法格式明确拒绝 | P0 | 把 txt 改名成 docx 拖入，被拒绝并提示，不白屏 |
| FR-FILE-04 | 文件全程不离开本机 | P0 | Network 无上传请求；断网后仍可打开、预览 |

|---|---|---|---|

### 3.6 FR-MD Markdown

> 边界先说清：md **只做预览，不做编辑**。编辑内核（ONLYOFFICE / x2t）只认 OOXML 与 ODF，
> md 的字节进不了转换器，也不存在从 md 回写的通道。要编辑得另建文本编辑器，属独立需求。

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-MD-01 | 打开 `.md` / `.markdown` 并排版渲染：ATX 标题、有序/无序/嵌套列表、围栏与缩进代码块、管道表格、引用、水平线、粗体/斜体/删除线/行内代码/链接 | P0 | 用验收样例打开，各元素显示为对应排版而非纯文本；1 秒内出内容 |
| FR-MD-02 | md 不进入编辑器：编辑入口禁用并说明原因 | P0 | 打开 md 时「编辑」按钮为禁用态且 tooltip 说明原因；强行切换不加载 199 MB 内核 |
| FR-MD-03 | 编码自动识别：UTF-8（含 BOM）/ UTF-16（BOM）/ 回退 GB18030 | P1 | GBK 保存的 md 打开后中文正常，顶部提示「按 GB18030 解码」；尾部被截断的 UTF-8 不被误判成 GBK |
| FR-MD-04 | 超长文件有上限并提示，不卡死 | P1 | 超过 20000 块或 4 MB 时只渲染前部，顶部说明已截断 |
| FR-MD-05 | md 中的 HTML 不执行 | P0 | 文件里的 `<script>`、`onerror` 不产生弹窗，只作为文字显示 |
| FR-MD-06 | 不支持的结构如实降级，不静默吞掉内容 | P1 | 任务列表 `- [ ]`、脚注、Setext 标题显示为纯文本；界面说明「支持范围」 |

### 3.7 FR-AGENT AI 辅助写作

> 定位：**只辅助，不代写**。不做整篇生成，不自动改写正文。
> 隐私前提：默认完全本地处理；仅当用户明确确认后，才把**选中的那段文字**发送给 AI 服务。

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-AGENT-01 | 助手入口默认关闭，开启后才出现 | P0 | 默认 `agentEnabled = false`，面板不渲染；Network 里没有任何 AI 域名请求 |
| FR-AGENT-02 | 选中文本后出现行内操作菜单：润色 / 扩写 / 缩写 / 翻译 / 继续写 | P0 | 选中 20 字以上时菜单出现；未选中时不出现；菜单项各点击一次都有响应 |
| FR-AGENT-03 | 发送前必须二次确认，并显示将发送的字数与内容预览 | P0 | 点击任一操作后弹确认框，含「将发送 N 字」与前 50 字预览；取消则不发请求 |
| FR-AGENT-04 | 只发送选区，不发送整篇文档 | P0 | 抓包确认请求体只含选区文字（可附带前后各 ≤200 字语境），不含其他段落、文件名 |
| FR-AGENT-05 | 结果先预览后应用，不自动覆盖正文 | P0 | 返回结果显示在候选卡片；点「替换」才写入；点「丢弃」正文不变 |
| FR-AGENT-06 | 应用结果后可一键撤销 | P0 | 替换后按 Ctrl+Z 能完整还原为替换前内容 |
| FR-AGENT-07 | 流式输出可中断，中断后正文不变 | P1 | 生成过程中点「停止」，立即停止接收，正文与撤销栈均未改变 |
| FR-AGENT-08 | 异常有可读提示，不白屏 | P0 | 断网 / 401 / 限流 / 超时四种情况分别给出可读文案与重试入口 |
| FR-AGENT-09 | API Key 不落盘 | P1 | 关闭页面后重新打开，Key 需重新输入；localStorage 中不存在明文 Key |
| FR-AGENT-10 | 超长选区有上限 | P1 | 选区超过 2000 字时提示「选区过长，请分段处理」，不发请求 |

## 5. 端到端验收场景

| 场景 | 步骤 | 通过标准 |
|---|---|---|
| A 只读查看 | 拖入 docx | 1 秒内显示内容；点击正文无光标 |
| B 编辑保存 | 点「编辑」→ 改内容 → 保存 | 光标在文字行内；下载文件含修改 |
| C 多文件切换 | 拖入 docx、xlsx、pptx 后来回切换 | 内容正确切换，无残留、无报错 |
| D 异常不白屏 | 使静态资源缺失后点「编辑」 | 界面保留，出现红色横幅，可切回预览 |
| E 局域网访问 | 另一设备经内网地址打开 | 页面可打开，预览可用 |
| F Markdown | 拖入 md 样例 | 标题/列表/代码/表格/引用正确排版；`<script>` 不弹窗；「编辑」按钮禁用 |
| G AI 润色 | 选中一段 → 点「润色」→ 确认 → 点「替换」→ Ctrl+Z | 只发送选区；候选先显示后应用；撤销可还原；全程无整篇上传 |
