## 1. 范围与约定

覆盖浏览器端的外部可见功能：打开、预览、编辑、保存、界面反馈、错误处理、配置开关。
不覆盖部署运维、桌面打包、协作与账号。

| 字段 | 含义 |
|---|---|
| 编号 | `FR-<模块>-<序号>`，全仓库唯一，Issue 可直接引用 |
| 优先级 | P0 必须 / P1 应该 / P2 可选 |
| 验收标准 | 必须可判断真假 |

## 2. 非目标

宏 / VBA、多人协作与版本历史、账号与云存储、复杂排版高保真、从零开发 Office 引擎、
PDF 注释与表单。

## 3. 功能需求

### 3.1 FR-FILE 打开

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-FILE-01 | 点击按钮选择文件，可一次选多个 | P0 | 选 3 个文件后侧栏出现 3 条记录；可单独关闭 |
| FR-FILE-02 | 拖放到窗口任意位置打开 | P0 | 拖入显示虚线遮罩，松开后打开 |
| FR-FILE-03 | 按扩展名 + ZIP 头双重识别，非法格式明确拒绝 | P0 | 把 txt 改名成 docx 拖入，被拒绝并提示，不白屏 |
| FR-FILE-04 | 文件全程不离开本机 | P0 | Network 无上传请求；断网后仍可打开、预览 |

### 3.2 FR-PRV 预览

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-PRV-01 | 打开后默认进入预览，支持 docx / xlsx / pptx / pdf | P0 | 四种格式各打开一次均能显示内容，1 秒内出内容 |
| FR-PRV-02 | 预览组件按格式按需加载 | P1 | 只打开 docx 时，Network 不出现 excel / pptx / pdf 的预览包 |
| FR-PRV-03 | 预览为只读 | P0 | 预览态点击正文无光标、无法输入 |
| FR-PRV-04 | 快速切换文档不错配 | P1 | 连续切换 3 个文件，最终显示的是最后一个 |

### 3.3 FR-EDT 编辑

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-EDT-01 | 可在预览 / 编辑间切换 | P0 | 双向切换不报错，不残留旧内容 |
| FR-EDT-02 | 编辑模式加载内核并打开当前文档 | P0 | 显示完整菜单栏与页面，状态栏出现「第 1 页 共 N 页」 |
| FR-EDT-03 | 光标位置与文字基线一致 | P0 | 点击正文，光标落在文字所在行内，无整行偏移 |
| FR-EDT-04 | 加载期间显示进度，超时说明原因 | P1 | 出现遮罩并显示「已等待 N 秒」；180 秒未完成时提示可能原因 |

### 3.4 FR-SAV 保存

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-SAV-01 | 取回编辑后的文件并下载 | P0 | 改内容后保存，重新打开可见修改 |
| FR-SAV-02 | 文件名沿用原文件名 | P1 | `报告.docx` 保存后仍为 `报告.docx` |
| FR-SAV-03 | 预览态保存语义为「另存原文件」 | P1 | 预览态保存下载原文件，状态栏说明未修改内容 |
| FR-SAV-04 | 失败时说明原因与替代操作 | P1 | 找不到导出入口时，提示去编辑器工具栏手动导出 |

### 3.5 FR-UI 界面与错误

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-UI-01 | 三栏布局：侧栏 / 编辑区 / 可选助手 | P0 | 默认侧栏 + 编辑区；助手默认关闭 |
| FR-UI-02 | 状态栏反馈最近一次操作结果 | P1 | 成功与失败文案不同且可读 |
| FR-ERR-01 | 任何未捕获异常不导致白屏 | P0 | 人为制造加载失败，界面框架保留并出现红色横幅 |
| FR-CFG-01 | 可通过配置关闭编辑器，退化为占位 | P1 | `features.editorEnabled = false` 后显示文件信息，不报错 |

## 5. 端到端验收场景

| 场景 | 步骤 | 通过标准 |
|---|---|---|
| A 只读查看 | 拖入 docx | 1 秒内显示内容；点击正文无光标 |
| B 编辑保存 | 点「编辑」→ 改内容 → 保存 | 光标在文字行内；下载文件含修改 |
| C 多文件切换 | 拖入 docx、xlsx、pptx 后来回切换 | 内容正确切换，无残留、无报错 |
| D 异常不白屏 | 使静态资源缺失后点「编辑」 | 界面保留，出现红色横幅，可切回预览 |
| E 局域网访问 | 另一设备经内网地址打开 | 页面可打开，预览可用 |
