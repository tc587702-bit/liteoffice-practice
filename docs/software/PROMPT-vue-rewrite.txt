0. 前置声明（违反任一条直接重做，不要交付）

  这是一个 Vue 3 项目，不是 React 项目。

  上一轮失败记录（务必避免重演）：
    - 产出为 React 工程：package.json 的 name 写成 react-project，
      依赖含 react / react-dom / react-router-dom / zustand
    - 未安装 docx / xlsx / pdfjs-dist 三个必需解析库
    - 额外引入 antd / @mui/material / @arco-design / @radix-ui /
      tdesign-react / framer-motion / recharts 等 20 余个无关 UI 库
    - 版本号臆造：typescript ^6.0.2、vite ^8.0.2、lucide-react ^1.6.0，
      npm install 必然失败
    - generation_meta 里 appearance_mode=light、背景 #ffffff、主色 #2563eb，
      与要求的纯黑 + #303032 + #0A84FF 完全相反

  本次硬性判定：
    - package.json 中不得出现 react、react-dom、react-router-dom、zustand、
      antd、@mui/*、@arco-design/*、@radix-ui/*、tdesign-*、
      framer-motion、recharts
    - src 下不得出现 .tsx / .jsx 文件
    - 出现上述任一，立即停止并重做


1. 不可变清单（最高优先级）

以下内容必须与墨刀产物完全一致，任何"优化""简化""重新设计"都视为不合格。

  文案
    所有标题、副标题、按钮文字、提示语、空状态文案、标签文字，
    逐字一致，不新增不删除。

  布局
    三栏结构、顶栏 68px、Hero 卡 60/40 双列、底部四格通栏、间距数值，全部保持。

  颜色
    背景纯黑 + 蓝紫径向光晕（透明度 0.07-0.09）

    主按钮 #0A84FF
    次级按钮 #3A3A3C
    文字 #F5F5F7 / #98989D / #A1A1A6 / #636366
    不得调色。

  圆角
    卡片 24px、格式胶囊 8px、主按钮全圆角药丸，不得改成其他值。

执行方式：

2. 工程结构

  技术栈：Vue 3 + Vite + TypeScript + vue-router + Pinia，不要 React
  路由：  / 首页，/editor 编辑页
  样式：  内联 CSS 抽成 SFC scoped 样式或独立 CSS 模块，不留大段内联 style
  脚本：  拆成 composable：useFileImport / useDocSession / useDocParse /
          useDocExport / useToast
  解析：  parseDocx / parseXlsx / parsePptx / renderPdfPages
          只搬位置 + 改 ES module 导出，不得重写算法，不得改变解析行为
  依赖：  仅 docx、xlsx(SheetJS)、pdfjs-dist
          不要 jszip（现用原生 DecompressionStream）
          不要 mammoth（现有代码没用它）
  跨页：  去掉 window.name，改 Pinia store + IndexedDB 数据层；
          路由只传文件 id，不传字节
  产出：  npm install / npm run dev / npm run build 三者必须全通

2.1 Tailwind 配置（缺这条会整片丢样式）

  npm 版 Tailwind 会 purge 未扫描的类，bg-[#303032] 这类任意值类会直接消失。
  tailwind.config.js 必须写：

    content: ['./index.html', './src/**/*.{vue,ts}']

  验收方式：npm run build 后打开 dist/index.html，
  首页 Hero 卡片背景必须是 #303032；若呈透明，说明 content 配错。

3. 首页规格

  顶栏

  左侧导航（三项，flex 垂直居中，带线框图标）

    AI 助手：浅灰文字 + #636366"预留"小标签

              点击弹 Toast"云端工作区正在开发中，目前请使用本地安全模式"，
              且不得夺走选中态

          蓝色药丸主按钮（上间距 32px）

  底部隐私通栏（与主卡片同宽）
    1x4 横向等距 flex，四格：本地处理 / 0次上传 / 无广告追踪 / 极速响应

    不得直接改 DOM 或写内联 style
    prefers-reduced-motion 下全部降级为静态


4. 编辑页规格

  同一套顶栏与侧栏，右侧为文档编辑区。

  必须真实可用
    文件内容渲染进可编辑区域
    工具栏真实作用：加粗 / 斜体 / 下划线 / 标题 / 列表
    撤销重做、字数统计、文档大纲跳转、阅读模式、未保存标记

  保存下载必须写入编辑结果
    md：导出编辑后的文本
    xlsx：SheetJS 回写，保留工作表名
    docx：docx 库回写，保留标题层级、列表、表格
    pptx / pdf：无法回写时必须明确提示"该格式暂不支持回写编辑结果"，
               允许导出文本/HTML 副本或下载原始文件；
               禁止静默导出与编辑结果不符的文件


5. 文件能力（真实数据，禁止示例）

  按钮选择 + 整页拖拽 + 拖拽框，三条入口都能导入本机真实文件：
  docx / xlsx / pptx / md / pdf

  会话列表显示真实文件名、大小、格式；可多文件、可切换、可移除；
  切换不同文件时内容绝对不能串

  解析防御性
    XML 节点的 children 可能不是数组（undefined / 单节点 / 字符串），
    一律归一化为数组再处理
    单个节点解析失败只跳过该节点，并提示"部分内容无法解析，已展示可读部分"
    不允许整份文档报错，不允许白屏，不允许静默失败

  会话与编辑内容用 IndexedDB 持久化，刷新后恢复
  大文件写入需 try/catch，配额不足时降级提示，不得崩溃


6. 补充硬要求（原需求未覆盖，但缺了会验收失败）

6.1 docx 内嵌图片必须渲染
    w:drawing → a:blip 的 r:embed → word/_rels/document.xml.rels
    → word/media/* → 按扩展名定 MIME → base64 data URL → img 标签
    尺寸：wp:extent 的 cx/cy（EMU）÷ 9525 → px
    不支持的格式（emf/wmf）显示占位，不报错

6.2 有序列表必须还原编号
    w:numPr 的 numId + ilvl → word/numbering.xml 的 abstractNum → lvl
    → numFmt（decimal / lowerLetter / lowerRoman 等）+ lvlText + start
    → 输出 1. 2. 3.，不得一律显示成圆点

6.3 导出必须自检
    导出后检查 ZIP 头为 PK\x03\x04
    再用自身 parseDocx 读回，比对段落数与首段文字
    不一致即报错，禁止静默成功

6.4 文本解码
    UTF-8 优先
    严格解码失败时回退 gb18030（旧记事本保存的 md 是 GBK）
    单文件上限 4 MB，超出截断并提示

6.5 性能与体积门槛
    dist 产物 ≤ 2 MB（含 pdf worker 可放宽到 4 MB）
    首屏到正文可读 ≤ 1 秒（本机、1 MB docx、清缓存）
    禁止任何 CDN / 外链，Network 域名只能是 localhost
    不得提交 node_modules/、dist/、public/onlyoffice/

6.6 安全
    md 与 docx 文本渲染必须转义，禁止用 v-html 直出未转义内容
    md 内的 script、onerror 不得执行
