# LiteOffice AI 助手 · 原型设计规格

版本 v1.0｜2026-10-24｜对应「原型设计三层模型」与「用户体验检查清单」

本文件把课堂上的三层模型（界面设计 / 视觉设计 / 用户体验）落到 LiteOffice 的 AI 助手与分享功能上，
并按 Nielsen 九条 + 智能体八条逐项对照，标出**已定 / 需注意 / 未做**。

---

## 一、用户任务与场景（三层模型的起点）

| 场景 | 用户原话 | 期望步数 |
|---|---|---|
| 润色一段 | "这段帮我改通顺" | 选中 → 1 次确认 → 1 次替换（3 步） |
| 问文档 | "这份文档讲了什么" | 打开面板 → 提问（2 步） |
| 抽表格 | "第 2 段表格给我" | 提问 → 下载（2 步） |
| 检查文档 | "有没有格式问题" | 1 次点击 → 看报告（1 步） |
| 分享给别人 | "发给组员一起改" | 点分享 → 复制链接（2 步） |

**设计约束**：任何场景的点击数不超过 3 步；超过就说明流程有问题。

## 二、界面设计

### 2.1 信息架构：什么放哪

```
┌────────────────────────────────────────────────────────────────┐
│ 顶栏：LOGO · 文件名 · [协作中 2人] · [分享] · [保存下载]          │
├──────────┬──────────────────────────────────┬──────────────────┤
│ 左侧栏    │ 主编辑区                          │ 右侧 AI 面板      │
│          │                                  │                  │
│ 本地文档  │  （文档内容，contenteditable）     │ 会话消息流        │
│ AI 助手   │                                  │ ─────────────    │
│ 云端工作区 │                                  │ 输入框 + 快捷问题  │
│ ────────  │                                  │ [发送]            │
│ 会话文件   │                                  │                  │
│ · 报告.docx│                                  │ 底部：模型 / 离线标识│
└──────────┴──────────────────────────────────┴──────────────────┘
```

- **左**：会话文件（已有），固定宽 200–240px
- **中**：编辑区，自适应
- **右**：AI 面板，宽 380px，**默认收起**（`agentEnabled=false` 时不渲染）
- 分享入口放顶栏右侧，与「保存下载」并列，属于同类操作（对外动作）

### 2.2 组件清单

| 组件 | 用途 | 关键细节 |
|---|---|---|
| 选区浮动菜单 | 润色/扩写/缩写/翻译/摘要 | 选中 ≥20 字才出现；表格内置灰 |
| 候选卡片 | 展示 AI 结果 | 四个按钮：替换 / 插入下方 / 复制 / 丢弃 |
| 确认弹层 | 发送前告知 | "将发送 137 字给 DeepSeek" + 前 50 字预览 |
| 消息气泡 | 面板对话 | 用户右侧蓝底，AI 左侧卡片底 |
| 引用徽章 | 标注依据 | `[第 2 段]` 可点击跳转到原文 |
| 问题卡片 | 诊断结果 | 折叠列表：位置 + 问题 + 一键修复 |
| 在线头像 | 协作状态 | 圆形首字母 + 颜色；>5 人显示 `+3` |
| 空状态 | 面板未开始 | 三个示例问题，点击即填（识别优于回忆） |

### 2.3 状态：五种必须都设计

| 状态 | 界面表现 | 不允许 |
|---|---|---|
| **空** | 面板显示 3 个示例问题 | 空白一片 |
| **加载** | 流式逐字出现 + "停止"按钮 | 只转圈无文字 |
| **成功** | 候选卡片 + 字数/耗时小字 | 静默改正文 |
| **拦截** | 明确原因 + 替代方案 | "操作失败"四个字 |
| **出错** | 原因 + 重试按钮 + 不影响正文 | 白屏 |

## 三、视觉设计

### 3.1 色彩：主色 + 语义色

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色（交互） | `#0A84FF` | 按钮、链接、选中态（已有） |
| 背景 | `#000000` + 径向光晕 0.07–0.09 | 已有 |
| 卡片 | `#303032` | 已有 |
| 次级面 | `#3A3A3C` | 已有 |
| **AI 专属** | `#BF5AF2`（紫） | **新增**：AI 生成内容左侧竖线 / 徽章，与人工内容区分 |
| 成功 | `#32D74B` | 在线点、保存成功 |
| 警告 | `#FF9F0A` | 文件较大、建议确认 |
| 危险 | `#FF453A` | 撤销链接、删除、不可逆操作 |
| 正文 / 副文 / 弱文 | `#F5F5F7` / `#98989D` / `#636366` | 已有三级 |

> 语义色的作用：**不靠文字也能分辨状态**（无障碍要求）。

### 3.2 字体层级

| 层级 | 字号 / 字重 | 用途 |
|---|---|---|
| 标题 | 17px / 600 | 面板标题、卡片标题 |
| 正文 | 15px / 400，行高 1.75 | 消息、正文 |
| 辅助 | 12.5px / 400 | 时间、字数、模型名 |
| 微标 | 11px / 500 | 徽章、角标 |

### 3.3 间距与圆角：统一变量

```
间距只允许 4 的倍数：4 8 12 16 24 32 48
卡片圆角     24px
按钮/气泡    12px 或 999px（药丸）
描边         1px solid rgba(255,255,255,0.08)
毛玻璃       rgba(28,28,30,0.75) + blur(20px)
```

### 3.4 图标与插画：少而一致

```
只用内联 SVG，24×24 视框，stroke 1.75
每个面板最多 3 种图标
不用图标表达关键信息（配文字）
```

## 四、用户体验（Nielsen 九条 + 智能体八条）

### 4.1 通用可用性

| # | 检查项 | 我们的做法 | 状态 |
|---|---|---|---|
| 1 | 状态可见 | 解析进度、流式输出、保存成功/失败都有文案 | ✅ |
| 2 | 贴近真实 | 不说"流式响应""token"，说"正在生成""约 137 字" | ✅ |
| 3 | 用户可控 | 可停止生成、可撤销替换、可丢弃候选、可撤销链接 | ✅ 设计已定 |
| 4 | 一致性 | 所有"危险动作"用红色 + 二次确认（撤销链接、覆盖保存） | ✅ |
| 5 | 防错 | 选区 >2000 字先拦；导出前提示版式损失；危险操作二次确认 | ✅ |
| 6 | 识别优于回忆 | 空状态给 3 个示例问题；格式胶囊直接列出支持格式 | ✅ |
| 7 | 高效 | Enter 发送、Shift+Enter 换行；常用动作放浮动菜单 | ⚠️ 快捷键未接 |
| 8 | 极简 | 面板只放消息 + 输入框，不堆设置项 | ✅ |
| 9 | 错误可恢复 | 断网/401/429/超时四类分别给文案 + 重试 | ✅ 设计已定 |

### 4.2 智能体专项

| # | 检查项 | 我们的做法 | 状态 |
|---|---|---|---|
| 1 | 边界声明 | 面板底部常驻一句："只处理你打开的文档；表格内不改写；不支持 OCR" | ✅ |
| 2 | 来源可追溯 | 回答附 `[第 N 段]` 徽章，点击定位并高亮 | ❌ 未实现 |
| 3 | 风险分级 | 三类分级：只读（绿）/ 需确认（橙）/ 不可逆（红） | ✅ 设计已定 |
| 4 | 拦截可理解 | 被拒时说明原因 + 替代："选区过长，建议分段；或改用『摘要』" | ✅ |
| 5 | 等待可感知 | 流式输出；工具调用时显示"正在读取第 2 段的表格…" | ✅ 设计已定 |
| 6 | 隐私透明 | 每次发送前显示字数与服务商；设置页写明"Key 仅本次会话有效" | ✅ |
| 7 | 无障碍 | 对比度 ≥ 4.5:1（已验）；状态不只用颜色（配文字/图标） | ⚠️ 键盘可达未验 |
| 8 | 响应式 | 窄屏（<900px）AI 面板变抽屉，左侧栏折叠成图标条 | ❌ 未做 |

### 4.3 三个未闭环项（要做完需要）

```
① 来源可追溯   约 1 天：解析回答里的 [第N段] → 映射到 docxItems 索引 → 滚动 + 高亮 2 秒
② 键盘可达     约 0.5 天：Tab 顺序、Esc 关闭面板、焦点环可见
③ 响应式       约 1 天：<900px 时面板抽屉化、侧栏折叠
```

## 五、一次完整交互的线框（润色场景）

```
① 用户选中一段              ┌ 浮动菜单 ┐
   实验一 1N4001 硅…        │ 润色 扩写 │
   （高亮 137 字）           │ 缩写 翻译 │
                            └──────────┘
② 点击「润色」
                            ┌ 确认发送 ────────────┐
                            │ 将发送 137 字给 DeepSeek │
                            │ "实验一 1N4001 硅二极管…" │
                            │        [取消] [确认]     │
                            └──────────────────────┘
③ 流式生成                  候选卡片
                            │ ✦ AI 生成             │
                            │ 实验一：1N4001 型硅二极管 │
                            │ 伏安特性的测量…          │
                            │ [替换] [插入下方] [复制] [丢弃] │
④ 点「替换」→ 写入正文 + 压入撤销点
⑤ Ctrl+Z 可撤销
```
